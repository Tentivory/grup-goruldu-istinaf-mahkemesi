# Grup Görüldü İstinaf Mahkemesi

Resmi adı uzun, kısa adı daha da kırıcı: **GÖRÜLDÜ**.

Bu kurum, bir mesajın okunup cevaplanmamasını hafife almaz. Hafife almak zaten mahkemenin işi değil; mahkeme o işi grup sohbetine bırakmıştır. Biz sadece tutanak tutarız, mazereti tartarız ve gerekirse “yazıyorum…” balonunu temyiz ederiz.

Patates yoktur. Dolmuş yoktur. Buzdolabı ışığı bu dosyada tanık değildir. Tanık, mavi tikin kendisidir.

## Neden var

Çünkü “gördüm, meşguldüm” cümlesi artık bir savunma değil, bir tür iklimdir. İklimi yargılamak için kanun gerekir. Kanun yoksa Python yeter.

## Kurulum

```bash
python3 goruldu_istinaf.py
python3 goruldu_istinaf.py --dakika 47 --emoji 3 --soru 1 --kisi 14 --mesaj "akşam gelir misin"
```

Bağımlılık yoktur. Mahkeme dışa bağımlı olmayı da “görüldü” sayar.

## Usul

1. Mesaj düşer.
2. Mavi tik düşer.
3. Cevap düşmez.
4. İstinaf düşer.
5. Karar düşer, kimse okumaz, dosya kapanır. Bu son madde mahkemenin kendi içtihadıdır.

## Emsal

- 12 dakika altı: “insan” sayılır.
- 12–40: “yazıyorum” balonu şüpheli sanık.
- 40–180: mazeret dilekçesi zorunlu.
- 180 üstü: dosya “görüldü, evrende yer kapladı” diye arşivlenir.

## Lisans

Okudun, cevap yazmadın. Lisans budur.
